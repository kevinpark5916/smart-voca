# 스마트 보카 — 단어장 웹 앱

영단어를 날짜별로 외우고, 시험으로 확인하고, 학습 진척을 보는 웹 앱입니다. 데이터는 SQLite에 저장합니다.

## 주요 기능

- **단어**: 직접 추가, 수정, 삭제 (학습 기록이 있는 단어는 삭제 불가), 검색, CSV 가져오기·내보내기
- **암기**: 하루 학습량만큼 일차별 진도, 카드 뒤집기, 알았음·다시 표시, 되돌리기. 복습에는 '다시' 단어와 자주 틀린 단어를 섞음
- **시험**: 문제 수, 방향(영→한, 한→영, 섞기), 형식(단답형, 4지선다, OX) 선택. 틀린 단어만 다시 시험 가능
- **통계**: 진도 현황, 날짜별 정답률 추이 그래프, 자주 틀린 단어 TOP 10
- **설정**: 하루 학습량, 복습 수, 시험 문제 수, 가중치, 화면 테마

## 고른 DB

**SQLite**. 파일은 `DB_PATH` 환경변수가 가리키는 곳에 만들어집니다. 컨테이너에서는 `/data/voca.db`입니다. 처음 실행하면 테이블과 기본 단어 2,000개가 자동으로 들어갑니다.

## 실행 방법

### 1. 로컬에서 실행 (개발)

Python 3.11 이상이 필요합니다.

```bash
python -m pip install -r requirements-web.txt
cd src
python run_web.py
```

브라우저에서 `http://127.0.0.1:5000`을 엽니다. 데이터는 `data/` 폴더에 저장됩니다.

### 2. Docker 이미지로 실행

```bash
docker build -t smartvoca-web .
docker run --rm -p 8080:8080 -e SECRET_KEY=바꿀값 -v smartvoca-data:/data smartvoca-web
```

브라우저에서 `http://localhost:8080`을 엽니다. 데이터는 `smartvoca-data` 볼륨에 남습니다.

| 환경변수 | 기본값 | 설명 |
|----------|--------|------|
| `DB_PATH` | 개발: `data/smartvoca.db`, 컨테이너: `/data/voca.db` | SQLite 파일 위치 |
| `SECRET_KEY` | 없으면 실행할 때 무작위로 만듦 | 세션 키 (비밀값은 코드에 넣지 않음) |

### 3. 테스트

```bash
python -m pytest
```

## 프로젝트 구조

```
src/
  web/          Flask 웹 앱 (API 블루프린트, 정적 화면)
  services/     암기·시험·단어 흐름
  study/        일차 계획, 연속 학습일
  quiz/         출제 가중치, 문항, 채점
  storage/      SQLite 저장소, CSV
  wsgi.py       운영 서버 진입점 (gunicorn)
  ui/           PyQt 데스크톱 화면 (과제 제출 범위 밖)
docs/           설계 문서 (방법론, 기획, 요구사항, 아키텍처, 데이터, 테스트, 구현계획, 배포)
tests/          자동 테스트
```

**설명**: 스마트 보카(SmartVoca)의 목적, 범위, 제약, 산출물 계획과 위험을 정의한다.

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | SmartVoca (스마트 보카) |
| 한 줄 설명 | Windows 데스크톱에서 영단어를 단계별로 암기하고, 취약 단어 중심으로 시험하는 학습 도구 |
| 개발 언어 | Python 3.11 이상 |
| GUI | PyQt6 |
| 저장소 | SQLite (이력), CSV (단어 입출력) |
| 사용 환경 | Windows 10/11, 개인 PC, 오프라인 |
| 상태 | 기획 초안 (v1.0) |

## 2. 배경과 목표

**배경**: 영단어 학습은 매일 일정량을 외우고, 틀린 단어를 반복해서 확인하는 과정이 핵심이다. 수기 단어장으로는 진도와 오답을 체계적으로 관리하기 어렵다.

**목표**

| ID | 목표 | 측정 방법 |
|----|------|-----------|
| G-1 | 단어 2000개를 기반으로 하루 단위 암기 진도를 관리한다 | 설정한 하루 분량대로 N일차 목록이 생성됨 |
| G-2 | 시험 결과를 바탕으로 취약 단어를 우선 출제한다 | 오답 단어의 출제 빈도가 정답 단어보다 높음 (테스트 데이터로 확인) |
| G-3 | 학습 이력을 저장하고 기간별 보고서를 만든다 | 기간을 지정해 HTML 보고서가 생성됨 |

## 3. 범위 (Scope)

### 3.1 MVP (필수, 요구사항 FR-01 ~ FR-08, FR-13)

- 단어 2000개 CSV 데이터 제공
- 단어 목록 불러오기 / 저장
- 암기 모드 (플래시카드)
- 하루 단위 진도 생성
- 가중치 기반 랜덤 시험
- 출제 방향(한→영, 영→한, 혼합) 및 유형(단답형, 4지선다형, OX형) 선택
- 암기·시험 이력 저장 및 HTML 보고서
- 설정 저장 (config.json)

### 3.2 1차 개선 / 2차 개선 / 선택

상세 항목은 Requirement Spec의 FR-09 ~ FR-23을 따른다.

- **1차**: 단어 편집 GUI, 편집 거리 채점, 오답 단어장, 시험 결과 요약, TTS 발음
- **2차**: 간격 반복(SRS), 듣기 시험, 학습 통계·달력, Excel 보고서, DB 백업·복원, 시험 시간 제한
- **선택**: Windows 알림, 다크 모드, exe 배포

### 3.3 범위 밖 (Out of Scope)

- 모바일 앱, 웹 서비스
- 여러 사용자 계정, 로그인, 온라인 동기화
- UI 다국어 지원
- 외부 사전 API 연동 (뜻·예문은 CSV에 직접 기입)

## 5. 제약 조건과 가정

| ID | 구분 | 내용 |
|----|------|------|
| C-1 | 제약 | Windows 10/11, Python 3.11 이상에서 실행 |
| C-2 | 제약 | MVP는 인터넷 연결 없이 동작해야 함 |
| C-3 | 제약 | 개인정보(실명, 학번, 연락처)를 저장하지 않음 |
| A-1 | 가정 | 사용자는 1명이며 본인 PC에서만 사용함 |
| A-2 | 가정 | 단어 2000개는 개발팀이 초안을 작성하고, 사용자가 검토 후 확정함 |
| A-3 | 가정 | 일정 기한은 없음 (마일스톤은 순서만 정의) |

## 8. 위험 관리

| ID | 위험 | 영향 | 대응 |
|----|------|------|------|
| R-1 | AI가 작성한 단어 뜻·예문에 오류가 있음 | 잘못된 학습 | 사용자 검토 후 확정, 수정은 CSV로 반영 |
| R-2 | pyttsx3 음성이 PC에 설치된 영어 음성에 의존 | TTS 품질 저하 | 1차에서 음성 목록 확인, 음성이 없으면 기능 비활성화 |
| R-3 | 가중치 값이 적절하지 않아 출제가 치우침 | 학습 효과 저하 | 가중치 값을 config.json에서 조정 가능하게 구현 |
| R-4 | PyQt6 라이선스(GPL/상용) | 배포 시 제약 | 개인 사용 전제로 진행, 배포 전 재검토 (DR-01 참조) |
| R-5 | 범위 확장으로 MVP 지연 | 일정 지연 | 1차 이후 항목은 MVP 완료 전까지 구현하지 않음 |

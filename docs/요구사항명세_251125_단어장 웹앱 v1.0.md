# 요구사항 명세서 — 단어장 웹 앱

**파일 위치**: `docs/요구사항명세_251125_단어장 웹앱 v1.0.md`
**작성일**: 2026-11-25
**버전**: v1.0
**설명**: 과제 「소프트웨어 요건」(v1.1)의 VOCA-FR·VOCA-NFR·VOCA-SUB 요건마다 구현 여부, 구현 위치, 확인 방법을 정리한다.

## 0. 표기

- **구현**: 코드와 자동 테스트로 확인했다. 시연 항목은 화면에서 직접 확인해야 한다.
- **부분**: 일부만 구현했다. 비고에 빠진 부분을 적었다.
- **미구현**: 아직 없다.
- **대기**: 사용자 조작 또는 외부 설정이 필요하다.
- 테스트 이름은 `tests/` 파일 안의 함수 이름이다.

## 10. 추적 메모

- 내부 명세서(`ai-agent/claude/SmartVoca_Requirement_Spec_v1.0_261021.md`)의 `FR-xx` 항목은 데스크톱 MVP 기준이다. 과제 제출에는 이 문서의 `VOCA-xx`를 쓴다.
- 커밋 메시지에는 관련 VOCA ID를 적는다. 예: `feat: 단어 추가·수정·삭제 (VOCA-FR-001, VOCA-FR-002)`.
